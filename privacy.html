Privacy Policy

Last updated: 1/31/2026

Necessary cookies and storage tools will always be used. These are things like keeping your choices on whether you accepted cookies or not, what mode you last set your browser to (light, dark, or auto), and what your current count on the test counter is. Cookies (and privacy policy) acceptance is also stored in these storage tools. I also use cookies and storage tools for the use of google firebase firestore and firebase auth. These programs enable me to store chat data from the chat site and to login users to keep data secure. I collect user agent data to determine what platforms my website is used on which helps me determine which platforms to test my website on before releasing it to the public. To collect this user agent data, I use ua-parser-js which is a mainly used in node.js software that will decode user agents strings for me. All this code is open source on github. I also collect user ip data to determine the location of where my website is accessed for analytical purposes. If I am breaking any laws or there is something that should be changed, contact me.
